# LearnJSTSPlaywright

Beginner-friendly JavaScript practice examples covering the language fundamentals. The repository is organized by topic and currently includes:

- Basic output and arithmetic in `HelloWorld.js` and `Math.js`
- Variables and JavaScript engine notes in `JsEngine.js`
- Literal values, including numbers, `null`, and `undefined`, in `Literal/`
- Arithmetic, assignment, comparison, and logical operators in `Operator/`

## Run an example

Install [Node.js](https://nodejs.org/) and run an example from the project root:

```sh
node HelloWorld.js
node Operator/ConfusingOp.js
```

Each file is a standalone learning example; run other `.js` files the same way. Some operator examples currently have no `.js` extension.
