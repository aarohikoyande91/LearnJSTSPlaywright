# LearnJSTSPlaywright

Beginner-friendly, standalone JavaScript examples for practicing language fundamentals. The examples are organized by topic:

- Basic output, arithmetic, variables, and JavaScript engine notes in the root-level examples
- Literal values, including numbers, `null`, and `undefined`, in `Literal/`
- Arithmetic, assignment, comparison, and logical operators in `Operator/`
- Conditional statements in `ifelsestatement/` and `Switch/`
- Increment and decrement operators in `incre-decre/`
- `for`, `while`, and `do...while` loops in `loops/`, `whileloop/`, and `dowhile/`
- User input examples in `userinput/`

## Run an example

Install [Node.js](https://nodejs.org/), then run an example from the project root:

```sh
node HelloWorld.js
node Operator/ConfusingOp.js
node loops/forloop.js
node dowhile/retry.js
```

Each `.js` file is a standalone learning example; replace the path above to run another example. Some examples that collect user input may require an interactive terminal or a browser, depending on the file.
